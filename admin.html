How it works (realistic)

Each SSR has its own resource table (e.g. Russian: Coal/Iron/Timber/Oil/Gas/Gold). When a citizen works in their zone, the game rolls weighted random among that SSR's resources only using that SSR's weights (or global if no per-SSR override). Changing Estonian Oil Shale 10→2 makes Oil Shale rare only in Estonia — Latvian peat stays 10. This is how real Soviet geology worked: Donbas coal ≠ Baltic oil shale rarity. Use -spawnrates and -setspawnrate in Discord too (admin only).
